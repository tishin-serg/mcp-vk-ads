# VK Реклама: Безопасное подключение — MCP-инструмент (tool)

**MCP-инструмент (tool) для VK Рекламы:** Показывает временный безопасный способ подключения hardened-форка без передачи `client_secret` или access token через AI-чат.

Техническое имя: `start_login`

## Какую задачу решает

> Я хочу подключить VK Рекламу, не передавая секреты модели.

Инструмент объясняет временный local-token flow: access token получают вне AI-чата и задают локально для процесса MCP через `VK_ADS_TOKEN`.

## Когда использовать

Вызывайте, когда подключения ещё нет или `auth_status` показывает `configured=false`. Инструмент не принимает credentials и не делает сетевых запросов.

## Что нужно передать

Параметры не нужны. `client_secret`, refresh token и access token передавать инструменту или в чат нельзя.

## Что вернёт

Режим `local-token-only`, шаги по локальной настройке `VK_ADS_TOKEN`, предупреждение не передавать секреты через AI-чат и пустой список ожидаемых входных данных.

## Что изменится в VK Рекламе

Ничего. Инструмент только возвращает инструкцию; сетевых вызовов и изменений кабинета нет.

## Пример запроса

> Покажи безопасный способ подключить ВК Рекламу.

## Возможные ошибки и ограничения

Токен из `VK_ADS_TOKEN` не продлевается этим MCP автоматически. Это временный режим до появления защищённого постоянного credential storage. Не используйте старый upstream-подход с передачей `client_secret` через AI-клиент.
